# ROADMAP.md — ATHENA Future Vision & Expansion Roadmap

## Post-Hackathon Roadmap (2026–2027)

---

## Phase 1: Post-Hackathon Polish & Live Model Integration (Q3 2026)

- **Gemini 2.0 Integration**: Upgrade `LiveAIProvider` with fine-tuned system prompts for structured JSON analysis.
- **Real-Time Archival APIs**: Connect Narrative Memory to GDELT Project and Internet Archive APIs for live historical narrative tracking.
- **Browser Extension**: Launch Chrome/Edge extension allowing one-click claim investigation directly from social feeds (X, Reddit, YouTube).

---

## Phase 2: UNESCO MIL Classroom & Youth Ambassador Program (Q4 2026)

- **Classroom Workspace**: Educator dashboard for high school and university teachers to assign media literacy investigation challenges.
- **Multilingual Expansion**: Add support for all 6 official UN languages (English, French, Spanish, Arabic, Chinese, Russian) + Hindi.
- **Peer Verification Networks**: Allow students to submit community context notes (similar to Community Notes) reviewed by peer moderators.

---

## Phase 3: Global Scale & Open Standards (Q1-Q2 2027)

- **Open MIL Standard API**: Release open API endpoints for educational non-profits to embed ATHENA's Trust Passport into local media literacy portals.
- **Mobile Apps**: Native iOS and Android apps using React Native.
- **Deepfake & Synthetic Media Forensics**: Advanced client-side C2PA (Coalition for Content Provenance and Authenticity) metadata verification.
